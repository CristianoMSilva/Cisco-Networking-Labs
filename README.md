# Cisco Networking Labs

Hands-on labs from the **Cisco Networking Academy – Junior Cybersecurity Analyst** career path, built in Cisco Packet Tracer.

Each lab has the configuration, screenshots as evidence, the problems I ran into and how I solved them, and the security lessons from a SOC/Blue Team perspective.

## Labs

| # | Lab | Topics | Status |
|---|---|---|---|
| 01 | [Configure a Wireless Router and Clients](01-wireless-router-config/) | DHCP, WPA2, default credentials, APIPA and DNS troubleshooting | ✅ Completed |
| 02 | [Connect to a Web Server](02-connect-to-web-server/) | IP addressing, ICMP/ping, ARP, TTL, packet analysis (Simulation mode) | ✅ Completed |
